# Security Policy — brain-store

## Disclosure

Report vulnerabilities privately to https://github.com/Xtley001/brain-libraries/security/advisories.
Do not open a public issue. We acknowledge receipt within 48 hours.

## Supported Versions

| Version | Status |
|---|---|
| `0.1.x` | Supported |
| `< 0.1` | Unsupported |

## Scope

- PostgreSQL schema DDL/DML execution
- `psycopg` and `psycopg_pool` dependency supply chains
- CSV/JSON file persistence logic

Excludes PostgreSQL database server misconfiguration.
