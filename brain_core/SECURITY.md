# Security Policy — brain-core

## Disclosure

Report vulnerabilities privately to https://github.com/Xtley001/brain-libraries/security/advisories.
Do not open a public issue. We acknowledge receipt within 48 hours.

## Supported Versions

| Version | Status |
|---|---|
| `0.1.x` | Supported |
| `< 0.1` | Unsupported |

## Scope

- Python source in this package
- `python-dotenv` dependency supply chain

Excludes misconfiguration of the host environment.
